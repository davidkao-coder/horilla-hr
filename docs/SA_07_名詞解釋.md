# SA-07 名詞解釋（Think4U HRMS 全詞彙表）

> 依類別分組，每個名詞說明「是什麼 + 在本專案的意義/位置」。

---

## A. 專案 / 系統名稱

| 名詞 | 說明 |
|---|---|
| **Think4U HRMS** | 本系統。Think4U Tech 內部人事管理系統 |
| **Horilla** | 開源 HRMS（LGPL），本系統的 fork 基底。官方 github.com/horilla/horilla-hr |

| **後台 / Admin** | `/`，管理頁（HR/主管/系統管理員用）。⚠️ 不是 Django 內建的 `/admin/` |

## C. 認證 / 權限名詞

| 名詞 | 說明 |
|---|---|
| **User**（`auth_user`）| Django 內建帳號表。本系統 **username = 公司 Email** |
| **Employee** | Horilla 的員工主檔，1:1 對應 User |
| **Group**（角色）| Django 內建群組 = 本系統的「角色」（4 種）|
| **Permission** | Django 內建細粒度權限（`app.action_model`）|
| **superuser** | Django 最高權限旗標 |
| **AdminAccessGroup** | Think4U 自製表，給每個 Group 設 4 個旗標（見下）|
| **can_access_admin** | 該角色能否進後台 |
| **force_admin_only** | 該角色**強制只能用後台**（高管不需前台打卡）|
| **show_in_personal_reports** | 是否出現在個人出勤/請假報表（高管隱藏）|
| **acts_as_superuser** | 該角色成員視為 superuser |
| **直屬主管**（reporting manager）| Horilla 原生欄位 `EmployeeWorkInformation.reporting_manager_id` |
| **部門主管** | Think4U 加的 `Department.manager`；`get_effective_manager()` 會往上層部門回溯 |
| **is_manager()** | Think4U helper：直屬主管 **∪** 部門主管（**判主管一律用這個**）|
| **managed_employees()** | 該主管可管範圍：直屬下屬 ∪ 所管部門(含子部門) ∪ 自己 |
| **RolePageVisibility** | 角色 × 側邊欄項目的可見性設定 |
| **OAuth 2.0** | 第三方授權標準 |
| **Authorization Code Flow** | OAuth 流程之一：先拿 code、後端再換 token（本系統採用）|
| **SSO**（Single Sign-On）| 單一登入。本系統的 Google 登入 |
| **id_token** | OAuth 回傳的身分憑證（JWT 格式），內含 email 等 claims |
| **JWT** | JSON Web Token，三段式（header.payload.signature）|
| **claims** | JWT payload 內的欄位（`iss`/`aud`/`email`/`email_verified`）|
| **iss / aud** | issuer（發行者）/ audience（接收者，須等於 client_id）|
| **state** | OAuth 防 CSRF 的隨機字串（存 session，callback 時比對）|
| **redirect_uri** | OAuth 回跳網址，**必須與 Google Console 登記值完全一致** |
| **CSRF** | 跨站請求偽造。Django 用 token 防禦 |
| **CSRF_TRUSTED_ORIGINS** | 信任的來源網域清單（跨網域登入必設，否則 403）|
| **TOTP** | 基於時間的一次性密碼（本系統打卡驗證碼，24h 有效）|

## D. 業務名詞（HR / 出勤 / 計薪）

| 名詞 | 說明 |
|---|---|
| **出勤** | 員工上下班打卡與工時狀態 |
| **AttendanceActivity** | Horilla 的**打卡明細**表。★本系統唯一寫入的出勤表 |
| **Attendance / AttendanceLateComeEarlyOut** | Horilla 原生的出勤/遲早表，**本系統棄用**（空表）|
| **彈性工時** | 上班 09:30–10:00、下班 18:30–19:00 區間內視為準時 |
| **午休** | 12:30–13:30，不計工時 |
| **工時**（work_minutes）| (下班 − 上班) − 午休重疊 |
| **evaluate()** | 出勤判定核心函式，回傳 `AttendanceEvaluation` |
| **on_time / late / early_leave / late_and_early / absent / incomplete / on_leave** | 出勤 7 種狀態（正常/遲到/早退/遲到且早退/缺勤/未打卡完整或工時不足/請假）|
| **short_minutes** | 工時不足的分鐘數（< 8h 才有值）|
| **出勤異常紀錄** | 列出所有非正常日的報表（原名「遲到早退紀錄」）|
| **補打卡** | 忘記打卡後的事後補登申請（需簽核）|
| **外勤** | GPS 超出公司 200m 範圍的打卡，需填事由 |
| **Haversine 公式** | 球面上兩點距離公式（GPS 判定用）|
| **全薪**（gross）| 本薪 + 津貼(伙食/交通) + 加給(管理/技術管理/薪資) |
| **本薪**（base salary）| 薪資的基礎部分 |
| **津貼 / 加給** | 薪資的附加項目（本系統分兩群組顯示）|
| **日薪** | ⌈全薪 ÷ 30⌉（計薪基準 30 天）|
| **計薪基準 30 天** | 台灣慣例：月薪 ÷ 30 = 日薪（不論當月實際天數）|
| **實領**（net）| 應發全薪 − 勞保 − 健保 − 請假扣薪 + 其他加項 |
| **月薪制 / 時薪制**（pay_type）| monthly / hourly |
| **每月變動加項**（MonthlyPayExtra）| 逐月手填的 8 項（加班費/特休未休/三節禮金/代墊/全勤/行政助理費），**不計入投保薪資** |
| **無條件進位**（`math.ceil`）| 本系統所有金額的取整方式（2026-07 決策），且「先進位再後續計算」|
| **到職比例** | 到職當月：在職日曆天數 ÷ 當月天數，用來按比例計薪 |
| **pre-hire** | 月度矩陣中「未到職」的日子標記（不算缺勤）|

## E. 台灣勞動法規名詞

| 名詞 | 說明 | 在本系統 |
|---|---|---|
| **勞基法** | 勞動基準法 | 特休 §38、產假 §50 為主要依據 |
| **勞工請假規則** | 勞動部規則 | 病假半薪 §4、事假不給薪 §7 |
| **性別工作平等法**（性平法）| | 生理假 §14（半薪）|
| **勞保**（勞工保險）| 政府強制社會保險 | 費率 12.5%（普通事故 11.5% + 就保 1%），受僱者自付 20% |
| **就業保險**（就保）| 失業給付等，與勞保合併計收 | 含在 12.5% 內 |
| **健保**（全民健康保險）| | 費率 5.17%，受僱者自付 30%，眷屬計費上限 3 人 |
| **勞退**（勞工退休金）| 雇主 6% 提繳 | **雇主全額負擔，不從薪資扣除**（本系統不計算）|
| **投保薪資 / 投保金額** | 計算保費的基準金額，依政府**分級表**取級距，非實際薪資 | `labor_insured_salary` / `health_insured_salary` |
| **分級表 / 級距** | 政府公布的投保金額級距表（勞保 11 級上限 45,800；健保 48 級）| `LABOR_GRADES` / `HEALTH_GRADES` |
| **投保上限** | 勞保月投保薪資上限 45,800（高薪者以此計）| |
| **特休**（特別休假）| 依年資給予的有薪假 | 勞基法 §38：滿半年 3 天…滿 10 年起每年 +1 至 30 天 |
| **週年制** | 以「到職週年日」為給假基準 | 本系統獲假採此制 |
| **曆年制** | 以「1/1–12/31」為使用週期 | 本系統使用期採此制 |
| **Model B** | 本專案代號：**週年制獲假 + 曆年使用**的混合制（每次獲假拆兩段）| `LeaveAllocation` |
| **遞延** | 未休完的特休延到隔年 | 勞基法 §38-4；本系統**僅可遞延一年** |
| **事假** | 個人事務請假，**不給薪** | 比例 0.0 |
| **病假**（普通傷病假）| 全年 30 天內**半薪** | 比例 0.5；需附證明 |
| **公傷病假** | 職業災害導致，全薪 | 比例 1.0 |
| **生理假** | 每月 1 天，**半薪**，前 3 天不計入病假 30 天 | 比例 0.5 |
| **公假** | 依法令應放假（如兵役、選舉）| 比例 1.0 |
| **婚假 / 喪假 / 產假 / 產檢假 / 陪產假** | 法定有薪假 | 比例 1.0；須走「給假申請」|
| **補休** | 加班換休（非法定假別）| 比例 1.0 |
| **給薪比例**（pay_ratio）| 本系統概念：1.0 不扣 / 0.5 半扣 / 0.0 全扣 | `LEAVE_PAY_RATIO` |

## G. 部署 / 維運名詞

| 名詞 | 說明 |
|---|---|
| **`.env` / `.env.prod`** | 環境變數檔（機密），**不進版控**；`.example`/`.dist` 為範本 |
| **entrypoint.sh** | 容器啟動腳本：還原 auth migration patch → makemigrations → migrate → compilemessages → collectstatic → 建 admin → 啟 gunicorn |
| **collectstatic** | Django 收集靜態檔到 `staticfiles/` |
| **health check** | `/health/` 端點；⚠️ DEBUG=False 時純 HTTP 回 **301**（正常），檢查要帶 `X-Forwarded-Proto: https` |
| **301 / 500 / 000** | 部署常見狀況：301=HTTPS 轉向（正常）、500=多為 DB 空/migration 失敗、000=連不上（容器啟動中）|
| **SECURE_SSL_REDIRECT** | Django 設定：強制 HTTP→HTTPS（DEBUG=False 時啟用）|
| **X-Forwarded-Proto** | 反向代理告知原始協定的標頭 |
| **HSTS** | 強制瀏覽器只用 HTTPS 的標頭（本系統設 1 年）|
| **certbot / Let's Encrypt** | 免費 TLS 憑證工具 / 憑證頒發機構（自動續期）|
| **pg_dump / psql** | PostgreSQL 備份 / 命令列客戶端 |
| **ngrok** | 把本機服務暴露到公網的隧道工具（手機測試用）|
| **management command** | Django 自訂指令（`python manage.py xxx`）|
| **cron / crontab** | Linux 排程 |
| **MSYS_NO_PATHCONV** | git-bash 環境變數，設 1 可避免 `/app/...` 被轉成 Windows 路徑 |
| **unrelated histories** | Git 兩分支無共同祖先，merge 需 `--allow-unrelated-histories` |
