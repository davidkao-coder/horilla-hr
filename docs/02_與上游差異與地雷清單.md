## 4. 地雷清單（症狀 → 原因 → 正確做法）

### 🔴 M1. `attendance/views.py` 是死檔
- **症狀**：改了 `attendance/views.py` 完全沒效果。
- **原因**：`attendance/views/` 是 **package**，同名 module 被蓋掉，永遠不會被 import。
- **做法**：改 `attendance/views/views.py`。

### 🔴 M2. 原生 `Attendance` / `AttendanceLateComeEarlyOut` 表是空的
- **原因**：Think4U 的 GPS 打卡與 Excel 匯入**只寫 `AttendanceActivity`**，Horilla 原生那兩張表棄用。
- **做法**：所有出勤報表/計算一律以 `AttendanceActivity` + `think4u/attendance_compute.py` 為準。看到用原生表的原生頁面，資料對不上是正常的。

### 🔴 M3. 重建 image 後 makemigrations/migrate 全炸（NodeNotFoundError: auth.0013）
- **原因**：Horilla 用 `User.add_to_class("is_new_employee", ...)` 把欄位掛在內建 auth app，該 migration 檔存在 **site-packages 內**，rebuild image 就消失，整個 migration graph 斷掉。
- **做法**：已修——migration 檔收在 `horilla/auth_migrations_patch/`，`entrypoint.sh` 啟動時自動複製回去。**看到 NodeNotFoundError 先檢查這個**。

### 🟠 M4. Horilla 諸多 model 的 `save()` 與 `clean()` 不相容
- **症狀**：程式化建立 JobPosition / Employee 等物件時拋 TypeError。
- **做法**：批次腳本先 `Model.save = dj_models.Model.save` 還原（seed、import 命令內都有範例，搜 `_patch_save`）。

### 🟠 M5. `HorillaCompanyManager` 有 process-wide cache
- `_T4U_DISTINCT_CACHE` 以 (model_label, selected_company) 為 key。新增公司或改 company_filter 行為時要意識到 cache 存在（重啟即清）。

### 🟠 M6. 前後台分離 middleware 的路徑白名單
- `think4u/admin_gate_middleware.py` 的 `ALLOWED_PREFIXES`：新增「登入前/公開」頁面要加進去，**前綴不要帶結尾斜線**（曾因 `/logout/` vs `/logout` 踩雷）。

### 🟠 M7. 員工編輯頁欄位是「泛用迴圈」渲染
- `employee/templates/employee/create_form/personal_info_as_p.html` 用 for 迴圈吐所有表單欄位；薪資欄位（pay_type 等 10 個）在迴圈內**被明確略過**、改由 `think4u/salary/pay_type_section.html` 獨立區塊渲染。新增表單欄位時注意會不會被迴圈重複渲染。

### 🟡 M8. `.env` 有兩個層級
- 開發：`honsi-hrms/.env`（settings 直讀）+ `docker-compose.override.yaml` 的 environment（後者優先注入 OS env）。
- 正式：`.env.prod` 由 compose `--env-file` 插值傳入。改設定要想清楚在哪一層。

### 🟡 M9. compilemessages 只能編 zh_Hant
- 其他語系（fr/de）的 po 有格式 bug，全編會失敗：一律 `compilemessages -l zh_Hant`。

### 🟡 M10. po 檔加翻譯注意重複 msgid
- 同 msgid 在檔內出現兩次 → compile 直接 fatal。加新條目前先 grep。
- 另外注意共用 msgid 的語境衝突（例：`Condition` 已被譯為「狀態」，郵件自動化改用 `Trigger Condition`）。

### 🟡 M11. git-bash 的路徑轉換
- `docker compose exec` 帶 `/app/...` 參數前要 `export MSYS_NO_PATHCONV=1`。

### 🟡 M12. migrations 預設被 gitignore
- `.gitignore` 有 `**/migrations/**`，實際需要的 migration 都是 `git add -f` 進版控（think4u 全系列都有追蹤）。新增 migration 記得 force add，否則同事/伺服器上 makemigrations 會生出**不同名字**的 migration 造成分歧。

### 🟡 M13. 正式環境 DEBUG=False 的行為差異
- `SECURE_SSL_REDIRECT=True`：直接打 http 會 301（健康檢查要帶 `X-Forwarded-Proto: https`）。
- 錯誤只回 500 無 traceback → 看 `docker compose logs server`。

## 5. Think4U 自製模組地圖（think4u/ app）
| 模組 | 功能 |
|---|---|
| 出勤 | GPS 打卡（portal）、出勤規則、月度統計矩陣、補打卡審核、出勤異常紀錄、Excel 匯入/匯出 |
| 計薪 | 勞健保級距、薪資組成、時薪制、投保薪資、請假扣薪、到職比例、月度試算+匯出 |
| 假勤 | 特休 Model B（週年制+遞延）、預設假別、給假申請、加班指派（主管→員工→HR）|
| 權限 | AdminAccessGroup（前後台分離/force_admin_only/acts_as_superuser）、RolePageVisibility、審核關卡管理（**尚未串進實際流程**）|
| 其他 | AuditLog 全庫稽核、Google SSO、健保眷屬明細、組織編輯（部門樹+主管）|
